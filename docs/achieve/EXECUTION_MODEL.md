## Status of the old mounted-workspace model

The previous `mount-first` execution model is no longer the active design.

That older model assumed:

- mounted paths were the primary collaborative surface
- `section exec` existed as a fallback execution helper
- execution semantics should be defined before the sync-workspace route was settled

Those assumptions are no longer the current project direction.

## If execution is revisited later

Any future execution design should be rebuilt from the current source/path sync route, not from the old mounted-workspace document.
