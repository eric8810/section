# GitHub Release Package

This folder contains the working package for the first public GitHub release of Section.

## Included Files

- [GITHUB_RELEASE_DRAFT.md](GITHUB_RELEASE_DRAFT.md)
  - draft release notes/body for the GitHub release page
- [DEMO_SCRIPT.md](DEMO_SCRIPT.md)
  - 30 to 60 second demo flow for the release post and screen recording
- [PUBLISH_CHECKLIST.md](PUBLISH_CHECKLIST.md)
  - step-by-step release execution checklist
- [ASSET_CHECKLIST.md](ASSET_CHECKLIST.md)
  - the release assets to attach or reference

## Suggested First Version

Use an honest early version such as:

- `v0.1.0-alpha.1`

That communicates:

- the current source/path sync line is real
- the control plane is usable
- the product is still early and not pretending to be feature-complete
