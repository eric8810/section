# GitHub Release Asset Checklist

## Required for first release

- release title
- release body
- version tag
- Quick Start link
- User Manual link
- one square launch image
- one workflow image
- one short demo recording

## Recommended attached assets

- `section-launch-square.png`
- `section-social-card.png`
- `section-workflow-card.png`

## Recommended linked assets

- `docs/QUICKSTART.md`
- `docs/USER_MANUAL.md`
- `docs/PRODUCT.md`
- `docs/SYNC_MODEL.md`

## Binary / install notes

If install binaries are not yet attached to the release, the page should still include:

- current install path
- supported install surfaces
- current status of planned install surfaces

For the next execution tasks, those surfaces are:

- Homebrew
- npm (`npm install -g` / `npx`)
- official agent skill

## Release-page media order

Use this order:

1. square launch card
2. workflow card
3. Quick Start link
4. demo video / GIF

That order keeps the release page readable for both:

- first-time visitors
- technical evaluators
